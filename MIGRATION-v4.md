# Migrating to v4

v4 is a hard cut with no shims (UIR-D75). Every breaking change adds its row here in the same change
that makes it: what the old API or token was, what replaces it, the codemod or agent migration
prompt that moves a call site, the decision behind it, and the pull request that made it.

The rows feed the v4 codemods, the agent migration prompts and the migration guide. Keep one row per
old name; when one old name splits into several new ones, list each in **New**.
