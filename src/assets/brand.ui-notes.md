# Brand assets — UI notes

Surface: `FragmentsLogo` (symbol), `FragmentsWordmark` (lockup), `FragmentsBrand` (lockup that
collapses to the symbol below the md breakpoint). Artwork is generated by
`assets/fonts/fragments-sans/wordmark.py`; never hand-edit `fragments-wordmark-artwork.ts`.

## What works

- One brand element per surface: apps wrap `FragmentsBrand` in their own home link and pass a
  height. The symbol-only state reuses the symbol's size inside the lockup
  (`fragmentsWordmarkSymbol.height`), so the switch does not change the mark's size.
- The lockup is a CSS mask filled with `currentColor`, so it follows the surrounding ink and
  theme with no image swap.
- `collapse="never"` keeps the lockup for footers, sign-in and brand pages.

## What doesn't

- jsdom cannot evaluate the media query, so tests see both children; the browser shows one.
- At 14–16px the symbol's inner square closes up. That is the symbol art, not the lockup math.

## Improvement candidates

- A simplified small-size symbol (or tiled mark) for the 14–16px band.
- Container-query collapse for sidebars that are narrow on wide viewports.
