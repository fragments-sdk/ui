# ThemeToggle — UI notes

## 2026-08-13 — tray hooks

`--fui-theme-toggle-bg` (fallback tertiary) and
`--fui-theme-toggle-active-bg` / `--fui-theme-toggle-active-shadow` let a
host drop the segmented tray. `appearance="icon"` is a single button that
shows the current resolved theme and toggles light ↔ dark. Docs header uses
the icon appearance.
