# Decisions

Every decision that shapes `@usefragments/ui`, with its date, its reason and its undo. Code, tests
and notes cite a row by its ID, `UIR-D` plus a number.

- IDs are permanent and never reused. Newer rows supersede older ones; a row that replaces another
  names it.
- Rows 1 to 61 were restored on 2026-10-03 from the original ledger. They were edited to drop or
  restate context about tools and packages outside this one, and to point at the later rows that
  supersede them.
- The numbers on the `Reserved:` line belong to decisions recorded outside this package (scheduling,
  review process, other packages). Citing one fails the check, the same as a missing row.
- `pnpm run check:ledger` fails when a cited ID has no row. It prints the next free ID; add the row
  in the same change that cites it.
- How each rule is enforced lives in [RULE-CHECKS.md](RULE-CHECKS.md); breaking changes for the next
  major are listed in [MIGRATION-v4.md](MIGRATION-v4.md).
